# Exploratory notebooks

These notebooks document the exploratory stages of the research project.

They were originally developed while the project was located inside a
PyPSA-GB working tree and therefore contain relative references such as
`../../resources/network/`.

They are retained for **research provenance**, including the early physical
network analysis, horizon-sensitivity investigation and rejected generic
BESS counterfactual.

They are **not the primary standalone reproducibility interface** for the
final market-design results.

The final workflow is represented by the Python scripts in `scripts/`.
Model-dependent scripts use a separate sibling PyPSA-GB repository.

Expected local layout:

```text
parent-directory/
├── PyPSA-GB/
└── gb-market-design-bess/
```

The notebooks should therefore be interpreted as documented exploratory
research rather than polished production workflows.
